# Herdr Status Command

Эта команда отображает текущие метрики сессии и обновляет их в Herdr UI.

## Использование

```bash
/herdr-status
```

## Что показывает

- **Модель**: Текущая используемая модель
- **Длительность**: Время работы сессии
- **Статус**: Активная/Неактивная сессия
- **Токены**: Входящие/Исходящие токены (если доступны)
- **Кэш**: Чтение/Запись кэша (если доступно)
- **Расходы**: Текущие затраты (если доступны)

## Пример вывода

```
╔══════════════════════════════════════════════════╗
║  Herdr Agent Status
╠══════════════════════════════════════════════════╣
║  Model: qwen3.5-122b
║  Status: ● working
║  Duration: 12m 34s
║  Tokens: 12K / 8K
║  Cache: 5M / 256K
║  Cost: $0.02
╚══════════════════════════════════════════════════╝
```

## Обновление в Herdr

Команда автоматически отправляет метрики в Herdr для отображения в:
- Статус-баре панели
- Label табов
- Workspace информации
