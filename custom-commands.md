# Custom Commands

## `/grill-me [topic]`

Запускает скилл `grill-me` для интерактивного допроса по указанной теме.

**Примеры:**
- `/grill-me` — запустить допрос в текущем контексте
- `/grill-me мой план архитектуры` — допросить по конкретному плану
- `/grill-me решение использовать PostgreSQL` — проверить архитектурное решение

**Как работает:**
1. Агент активирует скилл `grill-me`
2. Задаёт провокационные вопросы по теме
3. Выявляет слабые места в твоих решениях

---

## `/caveman [lite|full|ultra|stop]`

Включает режим кратких ответов (см. `caveman` skill).

**Примеры:**
- `/caveman` — включить lite режим
- `/caveman full` — полная краткость
- `/caveman ultra` — максимальное сжатие
- `/caveman stop` — вернуться к обычному режиму
