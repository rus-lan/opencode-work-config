# /grill-me

Интерактивный допрос плана или решения.

## Использование

```
/grill-me                              # запустить в текущем контексте
/grill-me <тема>                       # допросить по конкретной теме
```

## Как работает

1. Загружается `skill("grill-me")` — скилл интерактивного допроса
2. Скилл задаёт провокационные вопросы, разбирая дерево решений шаг за шагом
3. Оркестратор только передаёт вопросы от скилла пользователю и ответы обратно
4. После допроса — запуск глубокого ресёрча по найденным слабым местам

## Что проверяет

- Архитектурные решения
- Выбор технологий
- Допущения и риски
- Альтернативные подходы
- Границы и ограничения

## Триггеры

Скилл также активируется при фразах:
- "прогони меня через grill-me"
- "запусти допрос"
- "grill my plan"
- "допроси мой план"

## Примеры

```
/grill-me
/grill-me мой план архитектуры
/grill-me решение использовать PostgreSQL
```
