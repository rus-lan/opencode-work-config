# RPC API шлюз: доступ к нодам

Шлюз стоит между вашим приложением и блокчейн-нодами. По сути это прокси, но с авторизацией, лимитами и единой точкой входа: вы подключаетесь к сети, шлёте запросы и забираете данные через один адрес. Поддерживаются основные методы и протоколы, которые ждёт типичный JSON-RPC клиент.

Аптайм держится на отметке 99.9%. Инфраструктура масштабируется под нагрузку, так что всплеск запросов её не роняет. Разработчику не нужно поднимать и обслуживать собственные ноды: этим занимается шлюз.

Чтобы отправить запрос, используйте конечную точку `eth_blockNumber` через ваш ключ доступа. Базовый адрес шлюза: https://api.example.com, и он принимает стандартные JSON-RPC вызовы.

```bash
curl -X POST https://api.example.com \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

Аутентификация идёт через заголовок. Ключ передаётся в каждом запросе, и без него шлюз ответит ошибкой. Платформа рассчитана на продакшн-нагрузку, поэтому к ней одинаково спокойно подключаются и небольшие команды, и крупные проекты с миллионами вызовов в день.

Вот, собственно, и весь старт. Дальше идёт ваш код и нужные методы.
