# دليل البدء مع بوابة RPC API ومنصة العُقد

بوابة RPC API هي الطبقة التي تصل تطبيقاتك بشبكات البلوكتشين. مهمتها بسيطة: توجيه كل طلب ترسله إلى العقدة الصحيحة. تجمع المنصة بين السرعة والموثوقية في واجهة واحدة، فلا تحتاج إلى ربط كل شبكة على حدة. تشرح هذه الوثيقة المفاهيم الأساسية، وتدفق المصادقة، ودورة حياة الطلب.

البوابة أكثر من وكيل بسيط. إنها طبقة تنسيق للعُقد. توزع حركة المرور عبر عقد متعددة كي تبقى الاستجابات سريعة ومتسقة. تحافظ المنصة على نسبة تشغيل تبلغ 99.9% في جميع المناطق المدعومة. والمصادقة هي أساس كل عملية، فهي تمنح كل فريق تحكمًا في الوصول والأمان معًا.

تبدأ بمصادقة كل طلب عبر مفتاح API يُمرر داخل ترويسة `Authorization`. عنوان URL الأساسي لجميع الطلبات هو https://api.example.com ولا يتغير بين الإصدارات. هكذا تركز على منطق تطبيقك بدلًا من البنية التحتية.

يبدو الطلب البسيط على النحو التالي.

```bash
curl -X POST https://api.example.com/v1/rpc \
  -H "Authorization: Bearer <your-api-key>" \
  -d '{"method":"getBlockNumber"}'
```

تعود الاستجابة خلال أجزاء من الثانية. حمولتها نظيفة وموثقة. لا تكتفي البوابة بالتحقق من طلبك، بل تضيف إليه معلومات تشخيصية تساعدك على فهم ما يجري. الاستدعاء الأول يكفي لتعرف كيف تعمل. الفكرة كلها أن تبني أسرع وتشحن أبكر دون أن تدير البنية التحتية بنفسك.
