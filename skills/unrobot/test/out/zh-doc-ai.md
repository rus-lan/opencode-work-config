RPC API 网关是节点平台的入口。请求先到网关，再分发到后端节点。我们的接口稳定，调用延迟低，长期运行也不容易出问题。架构上做了分层，新系统接入时改动很小。

接入只要一步。开发者在客户端里配置好 `endpoint`，就能开始发请求了。网关支持高并发，也能处理大批量的数据请求，所以业务量上来时不用担心被压垮。平台承诺 99.9% 的可用性。

这套网关覆盖了常见的调用场景，从查询到写入都能走同一个入口，不用再额外搭一层中间件。

下面是一个调用示例：

```bash
curl -X POST https://api.example.com -d '{"method":"eth_blockNumber"}'
```

就这些。配好地址，发出请求，剩下的网关会处理。
