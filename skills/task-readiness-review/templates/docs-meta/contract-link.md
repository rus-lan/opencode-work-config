# Шаблон: заглушка на внешний контракт

Назначение шаблона: когда контракт нельзя автосинхронизировать в
`services/<svc>/contracts/` (нет MCP-доступа к источнику, контракт живёт
только в Confluence и ещё не переведён в машиночитаемый вид и т.п.) — вместо
копии кладётся файл-заглушка по этому шаблону. Файл-экземпляр:
`services/<svc>/contracts/<contract-name>.md`.

## Фиксированные секции (порядок менять запрещено)

1. Система (обязательно)
2. Тип контракта (обязательно)
3. Источник (обязательно)
4. Дата проверки актуальности (обязательно)
5. Причина, почему не скопирован (обязательно)

## Скелет файла

````markdown
# {{contract-name}}

## 1. Система
{{system-name}}

## 2. Тип контракта
{{contract-type}}

## 3. Источник
{{source-url}}

## 4. Дата проверки актуальности
{{last-checked}}

## 5. Причина, почему не скопирован
{{reason-not-copied}}

<!-- stub: перенести при появлении MCP-автоматизации -->

<!-- EXTENSIONS -->
<!-- Опциональные секции добавляются здесь и только здесь. Порядок фиксированных секций выше менять запрещено. -->
````

## Таблица слотов

| Слот | Источник факта | Формат | Лимит | Если факта нет |
|---|---|---|---|---|
| `{{contract-name}}` | имя контракта как в источнике | kebab-case | ≤ 60 символов | — |
| `{{system-name}}` | Confluence / реестр интеграций | имя внешней или внутренней системы | ≤ 60 символов | `N/A (нет данных в источнике)` |
| `{{contract-type}}` | тип источника контракта | закрытый список: `openapi` \| `proto` \| `kafka-json` \| `table` \| `other` | закрытый список | — (тип обязателен всегда) |
| `{{source-url}}` | Confluence-страница / GitLab-путь, где реально лежит контракт | абсолютный URL или путь в GitLab | 1 строка | `N/A (нет данных в источнике)` |
| `{{last-checked}}` | дата, когда факт был последний раз сверен с источником | `YYYY-MM-DD` | 1 дата | `N/A (нет данных в источнике)` |
| `{{reason-not-copied}}` | почему автосинк невозможен сейчас | 1 строка, факт, не оценка | ≤ 160 символов | `N/A (нет данных в источнике)` |

## Самопроверка (чек-лист)

- [ ] Секции идут в порядке 1–5, ничего не переставлено.
- [ ] Front-matter содержит `id: <svc>-<contract-name>`, `type: contract-link`, `service: <svc>`.
- [ ] `{{contract-type}}` — значение строго из закрытого списка.
- [ ] Строка `<!-- stub: перенести при появлении MCP-автоматизации -->` присутствует дословно (фиксированная пометка-заглушка шаблона, не открытый вопрос команде — `TODO(team)` для неё не используется).
- [ ] `{{source-url}}` ведёт на реальный, проверяемый источник, а не на сам `_docs`.
- [ ] Файл не превышает 400 строк.
- [ ] Файл добавлен в `index.yaml` секции `services/`.

## Как используется скиллом

- check-id: DEP-02 (контракт)
- роль в проверке: если контракт нельзя положить в `contracts/` машиночитаемо, заглушка с системой, типом, источником и датой проверки доказывает, что контракт затронутой ручки известен и сверялся. Без неё описание логики неполно, и DEP-02 остаётся с пробелом.
