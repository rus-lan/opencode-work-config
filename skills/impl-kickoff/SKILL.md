# Impl Kickoff

## Description
Validate implementation readiness and kick off the development process.

## When to Use
- Before starting a new epic or story
- After a spec or design doc is finalized
- When transitioning from planning to implementation

## Workflow
1. **Readiness check** — confirm spec, dependencies, and rules are in place
2. **Environment check** — verify tooling, credentials, and local setup
3. **Scope contract** — review what's in and out of scope
4. **Dependency scan** — identify blocking items that must be resolved first
5. **Kickoff** — generate implementation brief and signal start

## Output
A kickoff report with readiness status, dependency list, and implementation brief.
