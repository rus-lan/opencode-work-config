# BMAD Retrospective

## Description
Run a retrospective after a sprint or milestone to identify improvements.

## When to Use
After completing a sprint, epic, or significant milestone.

## Workflow
1. Collect data — what was committed vs delivered
2. What went well — identify patterns to continue
3. What to improve — identify bottlenecks, friction points
4. Action items — create concrete, assignable improvements
5. Document results — write retrospective report

## Output
Retrospective report with action items and owners.
