# Перевод EN→RU: кальки и терминология

Переводить смысл, а не слова. Если русская фраза звучит как перевод, её нужно переписать,
даже когда она грамматически верна.

## 4. Нагромождение существительных

Английский склеивает существительные в цепочки, русский так не умеет.

| Калька | По-русски |
|---|---|
| Система контроля и управления версиями | Система управления версиями |
| Процесс оптимизации производительности приложения | Как ускорить приложение |
| Инструмент анализа пользовательского поведения | Инструмент, который показывает, как ведут себя пользователи |
| Платформа управления жизненным циклом данных | Платформа, которая ведёт данные от сбора до удаления |

**Правило:** цепочку из трёх существительных разбивают глаголом или придаточным.

## 5. Регистр

- Не смешивать «ты» и «вы» в одном тексте.
- Не смешивать канцелярит и сленг: «осуществляем движ» — хуже обоих вариантов.
- Разговорность допустима в колонке и блоге, но не в справочнике.
- Английские оценки громче русских: «revolutionary» → «новый», если нет факта.
- Английские предложения длиннее. Русское предложение делится, а не копирует запятые.

## 6. Что не переводить

- Код, команды, пути, имена переменных.
- Названия продуктов, компаний, сервисов.
- Общепринятые аббревиатуры: API, HTTP, JSON, PDF.
- Устоявшиеся профессиональные термины без русского эквивалента.
- Имена собственные — по принятой транскрипции, не по звучанию на слух.

## 7. Глоссарий

Терминология держится единой на весь документ. Один термин — одно понятие, без
синонимических качелей.

| Оригинал | Перевод | Не использовать | Комментарий |
|---|---|---|---|
| deploy | выпустить | деплоить, развернуть (если не про инфраструктуру) | Глагол зависит от контекста |
| feature | функция | фича, возможность (если не про продукт) | Выбрать один вариант |
| user | пользователь | клиент, человек | Клиент — только про платящего |
| workspace | рабочее пространство | воркспейс | Если нет устоявшегося |
| dashboard | панель управления | дашборд | Для нетехнической аудитории |

Правила ведения:

1. Заполнять по ходу перевода, а не после.
2. Один термин на документ, даже если в оригинале были синонимы.
3. Если термин спорный, выбрать вариант и зафиксировать в глоссарии, а не менять по вкусу.
4. Новый термин при первом упоминании — с пояснением в скобках, если аудитория может не знать.

## 8. Проверка перевода

1. Прочитай вслух: есть ли фразы, которые так не говорят?
2. Найди кальки из раздела 1.
3. Проверь ложных друзей из раздела 2.
4. Проверь цепочки существительных.
5. Сверь термины с глоссарием.
6. Проверь код, команды и названия — не переведены ли.
7. Сверь смысл: не потерялось ли отрицание, условие, число.
8. Прогони ветку A: стоп-слова, канцелярит, типографика.
