# Примеры до и после

Образцы трансформаций по типам проблем. Не шаблоны для копирования: смотри на логику
правки, а не на конкретные слова.

Цифры в примерах условные. Они показывают форму замены, а не разрешение выдумывать
данные: в реальной работе числа берутся из исходника или от пользователя, иначе ставится
плейсхолдер.

## 1. Корпоративный текст

**До:**
```
Наша компания является лидирующим поставщиком качественных образовательных решений.
Команда высококвалифицированных профессионалов с индивидуальным подходом к каждому
клиенту обеспечивает высокий уровень сервиса и максимально выгодные условия.
```

**После:**
```
Делаем учебные курсы для вузов и корпораций. В штате 12 методистов и 4 дизайнера,
каждый ведёт не больше трёх проектов. Работаем с 2014 года, выпустили 180 курсов.
```

**Что изменилось:** «является лидирующим поставщиком» → чем занимаемся; «команда
профессионалов» → состав и нагрузка; «высокий уровень сервиса» → конкретная модель работы;
«максимально выгодные условия» → удалено, фактов не было.

## 2. Канцелярит в объявлении

**До:**
```
В связи с проведением мероприятий по модернизации инфраструктуры осуществляется
временное ограничение доступа к ряду сервисов. Данные работы проводятся в целях
повышения надёжности и обеспечения бесперебойного функционирования системы.
```

**После:**
```
Обновляем серверы, часть сервисов временно недоступна. Работы займут 3–4 часа.
Напишем, когда всё заработает.
```

**Что изменилось:** три номинализации → глаголы; «ряд сервисов» → «часть»; пассив →
актив; «будет сообщено дополнительно» → «напишем».

## 3. Машинный блог

**До:**
```
Искусственный интеллект стремительно меняет ландшафт современного бизнеса. Не секрет,
что компании, которые успешно интегрируют ИИ-решения в свои рабочие процессы, получают
значительное конкурентное преимущество. В данной статье мы погрузимся в ключевые аспекты
внедрения искусственного интеллекта.
```

**После:**
```
ИИ меняет то, как компании работают. Одни автоматизируют рутину и экономят часы,
другие не понимают, с чего начать. Разберём, что реально даёт внедрение ИИ и где оно
буксует.
```

**Что изменилось:** «стремительно меняет ландшафт» → конкретное действие; «не секрет,
что» → удалено; «получают значительное преимущество» → без данных удалено; «погрузимся
в ключевые аспекты» → что именно разберём.

## 4. Кнопки

| До | После | Почему |
|---|---|---|
| Нажмите для начала | Начать | Кнопка и так нажимается |
| Осуществить поиск | Найти | Глагол вместо канцелярита |
| Получить больше информации | Подробнее | Краткость |
| Отправить форму | Отправить заявку | Понятно, что отправится |

## 5. Ошибка

**До:**
```
Ошибка! Что-то пошло не так. Попробуйте позже.
```

**После:**
```
Не удалось загрузить файл: он больше 10 МБ. Сожмите его или выберите другой.
```

**Что изменилось:** что случилось, почему, что делать. Без «Упс» и без обвинений.

## 6. Пустое состояние

**До:** «Список пуст».

**После:** «Создайте первый проект — это займёт 2 минуты».

**Что изменилось:** появилось следующее действие и время. Время — только реальное.

## 7. Форма

**До:**
```
Введите ваш электронный адрес *
Это обязательное поле
```

**После:**
```
Email
[ivan@mail.ru]
Отправим чек на этот адрес
```

## 8. Модалка удаления

**До:** «Вы уверены?» — «Ок» / «Отмена».

**После:** «Удалить проект „Физика 9 класс“?» — «Удалить» / «Оставить».

**Что изменилось:** назван объект, кнопки означают действия. Количество файлов добавляется
только если оно известно.

## 9. Эвфемизмы во внутренней коммуникации

**До:**
```
По итогам пересмотра стратегических приоритетов принято решение об оптимизации штата
и корректировке ожиданий по срокам проекта.
```

**После:**
```
Сокращаем пять человек из десяти в команде проекта. Релиз переносится с марта на май.
Причины: бюджет урезали вдвое, сроки были нереалистичны.
```

**Что изменилось:** эвфемизмы заменены фактами; названы причина и новые сроки.

## 10. Перевод

**До (калька):**
```
Наша платформа позволяет вам иметь бесшовный опыт управления вашими задачами
в течение всего дня.
```

**После:**
```
В платформе задачи собраны в одном месте: не нужно переключаться между сервисами.
```

**Что изменилось:** «позволяет вам иметь» → действие; «бесшовный опыт» → что именно
происходит; «в течение всего дня» → удалено.

## 11. Хороший текст

**До и после:**
```
Доставка за 2 часа по Москве. Курьер позвонит за 15 минут. Если опоздаем больше чем
на час, доставка бесплатно.
```

**Вердикт:** менять нечего. Все утверждения проверяемы, структура ясная, тон уместный.
Можно предложить одно улучшение: «опоздаем больше чем на час» → «опоздаем на час
и больше» — короче и однозначнее.

## 12. Юридический текст

**До:**
```
Исполнитель вправе приостановить оказание услуг при нарушении Заказчиком сроков оплаты
более чем на 10 календарных дней, уведомив Заказчика за 3 рабочих дня.
```

**Вердикт:** редактура не применяется. Смысл: при просрочке оплаты больше 10 дней
исполнитель может остановить работы, предупредив за 3 рабочих дня. Упрощение
формулировки создаст правовой риск — нужен юрист.

## 13. Список синонимов

**До:**
```
Долгий, нудный и утомительный процесс согласования.
```

**После:**
```
Согласование занимает две недели.
```

**Что изменилось:** три близких синонима заменены фактом. Если факта нет — «нудное
согласование».
