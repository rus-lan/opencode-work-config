# Русская типографика

Правила, которые проверяются механически. Ошибка здесь заметна сразу, даже если текст
хорош по смыслу.

## Кавычки

Основные — «ёлочки». Внутри — „лапки".

- Правильно: Он сказал: «Это важно».
- Вложенные: «Он сказал: „Это важно“».
- Никогда не использовать английские `"…"` и прямые `"..."` в русском тексте.

Английская фраза внутри русского предложения тоже берётся в ёлочки:
«Спросите ассистента: „When would you use this?"» — исключение только для кода.

В коде и встроенном коде — прямые кавычки, как требует язык.

## Тире

Три разных знака, не путать.

**Дефис (-)** — только в словах и частицах: кто-то, из-за, по-русски, всё-таки,
как-нибудь.

**Короткое тире (–)** — диапазоны без пробелов: 10–15 минут, 2020–2025, стр. 40–45,
понедельник–пятница.

**Длинное тире (—)** — всё остальное, с пробелами с двух сторон:

- Определение: Автоматизация — ключ к эффективности.
- Вставка: Навыки — один из самых мощных способов — настраивают агента.
- Вместо сказуемого: Компания — лидер рынка.
- Перед пояснением: Мы закончили сделку — это расширит линейку.

Никогда не писать два дефиса подряд вместо тире. В одном документе диапазоны оформляются
одинаково: только 15–30, не 15-30 и не 15 - 30.

## Списки

Тип маркера определяет заглавную букву и знаки в конце. Две системы, смешивать в одном
списке нельзя.

**Система 1: цифра с точкой или заглавная буква с точкой.** Каждый пункт — отдельное
предложение: заглавная буква, точка в конце.

```
1. Каждый элемент начинается с заглавной буквы.
2. В конце ставится точка.
3. Это относится и к коротким пунктам.
```

**Система 2: цифра со скобкой, строчная буква со скобкой, тире, маркер.** Строчная буква,
точка с запятой между пунктами, точка в конце последнего.

```
Навыки бывают трёх типов:
— автономные, без внешних инструментов;
— связанные с MCP-серверами;
— комбинированные.
```

### Markdown-списки

**Пункты — законченные предложения:** заглавная буква, точка в каждом.

```
- Навык загружается автоматически.
- Агент следует инструкциям из SKILL.md.
- Результат сохраняется в файл.
```

**Пункты — фразы:** строчная буква, точка с запятой, точка в конце.

```
Понадобится:
- файл SKILL.md с YAML-шапкой;
- описание сценариев;
- примеры входа и выхода.
```

**Пункты — слова:** строчная буква, запятая или точка с запятой, точка в конце.

```
Форматы:
- PDF,
- DOCX,
- PPTX.
```

### Частые ошибки

| Ошибка | Как исправить |
|---|---|
| Заглавная буква без точки | Добавить точку |
| Точка с запятой и точка вперемешку | Выбрать одну систему |
| Точка после последнего пункта при строчных | Оставить только в конце последнего |
| Разные маркеры в одном списке | Один тип маркера |

## Числа и даты

- Диапазоны — короткое тире без пробелов: 5–10 дней.
- Дроби — запятая: 3,5%.
- Проценты — знак слитно: 20%.
- Большие числа — неразрывный пробел: 15 000 ₽.
- Даты — 15 марта 2026 года, 15.03.2026. В одном документе один формат.
- Время — 14:30, 9:00. Диапазон — 9:00–18:00.
- Единицы — с пробелом: 5 кг, 10 км, 2 ч. Исключения: 20%, 30°.
- Порядковые — 1-й, 2-го, 10-й.

## Буква «ё»

Использовать последовательно: ещё, всё, её, приём, нёс, зовёт. Не смешивать «ещё» и «еще»
в одном тексте. В именах собственных — как у автора.

## Сокращения

- Расшифровывать при первом упоминании, если аудитория может не знать.
- Устоявшиеся (API, HTTP, PDF) не расшифровывать.
- Точка после сокращения: г., руб., млн, млрд — без точки (по современной норме),
  но в одном тексте единообразно.

## Пробелы и знаки

- Пробел перед тире и после, перед «—» нет исключений.
- Неразрывный пробел между числом и единицей, между инициалами и фамилией.
- Многоточие — один символ …, не три точки.
- Восклицательный знак — один. Два и больше — признак крика.
- Скобки: пробел снаружи, нет внутри: «текст (примечание) текст».
- Дефис в составных словах: интернет-магазин, а не интернет — магазин.

## Что проверять на выходе

1. Все кавычки — ёлочки, вложенные — лапки.
2. Тире трёх видов на месте, двойных дефисов нет.
3. Диапазоны одинаковые по всему тексту.
4. Списки не смешивают две системы.
5. «Ё» последовательно.
6. Числа, единицы, даты — в одном формате.
7. Нет английских кавычек и прямых апострофов в русском тексте.
