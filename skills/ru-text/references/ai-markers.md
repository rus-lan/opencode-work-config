# Маркеры машинного текста

Признаки, по которым русский текст читается как сгенерированный. Задача — не поймать
автора, а убрать механику. Один маркер в длинном тексте может быть случайным. Три и
больше — текст нужно переписывать, а не подчищать.

## 1. Лексические кальки

Слова, которые пришли из английских оборотов и почти не встречаются в живой речи.

| Маркер | Почему плохо | Замена |
|---|---|---|
| Погружаться, углубляться в тему | Калька delve | Разобраться, изучить, подробнее о |
| Ландшафт (угроз, возможностей) | Калька landscape | Ситуация, обстановка, сфера |
| Гобелен, полотно (метафора) | Калька tapestry | Разнообразие, сочетание, картина |
| Свидетельство, является свидетельством | Калька testament | Доказывает, говорит о том, что |
| Подчёркивать важность | Калька underscore | Показывает, напоминает |
| Ключевой, поворотный момент | Калька pivotal | Важный, решающий |
| Служить чем-то | Калька serve as | Быть, опустить глагол |
| Способствовать, воспитывать | Калька foster | Развивать, поддерживать, создавать условия |
| Высвободить потенциал | Калька unleash | Раскрыть, использовать |
| Обуздать технологию | Калька harness | Использовать, задействовать |
| Навигация по миру чего-либо | Калька navigating | Ориентироваться, разбираться |
| Демонстрировать (в каждом абзаце) | Калька showcase | Показывать, представлять |
| Более того, к тому же | Калька moreover | Удалить или перестроить фразу |
| В заключение | Калька in conclusion | Удалить или «Итог:» |
| Не только… но и… (в каждом абзаце) | Калька not only… but also | Перестроить фразу |

**Правило:** слово из таблицы один раз в длинном тексте — терпимо. Два раза или рядом
с другими маркерами — заменить.

## 2. Структурные маркеры

### 2.1 Правило трёх

Идеи насильно собирают в тройки, чтобы казаться полнее: «инновации, качество и надёжность»,
«быстрый, удобный и эффективный», ровно три пункта в каждом разделе.

**Что делать:** оставить столько, сколько есть по делу. Два пункта — нормально, пять — тоже.

### 2.2 Синонимические качели

Одно понятие называют разными словами, чтобы избежать повтора: продукт → решение →
инструмент → платформа. Пользователь → клиент → человек → специалист.

**Что делать:** один термин для одного понятия. Повтор лучше путаницы.

### 2.3 Злоупотребление тире

Тире в каждом втором предложении, будто это признак энергичного стиля.
«Наш продукт — это не просто инструмент — это революция — и она уже здесь».

**Что делать:** одно тире на абзац как ориентир, остальное — запятые и точки.

### 2.4 Жирный шрифт и списки-заголовки

Каждый пункт начинается с **Жирного Заголовка:** и двоеточия. Ключевые слова выделены
по пять раз в абзаце.

**Что делать:** убрать механические выделения. Оставить жирный для действительно
важного, лучше — ни для чего.

### 2.5 Одинаковые разделы

Все разделы построены по одному шаблону: вводное предложение, три пункта, вывод.
Или: определение, преимущества, вызовы, перспективы.

**Что делать:** варьировать. Где-то список, где-то проза, где-то короткий абзац без вывода.

## 3. Тональные маркеры

### 3.1 Сикофантия

«Отличный вопрос!», «Вы абсолютно правы!», «Это действительно важная тема»,
«Будущее выглядит многообещающим».

**Что делать:** удалить. Если оценка нужна, сделать её конкретной.

### 3.2 Следы диалога с чат-ботом

«Надеюсь, это поможет», «Если есть вопросы, спрашивайте», «Давайте рассмотрим подробнее»,
«Конечно!», «Разумеется!» в начале.

**Что делать:** удалить целиком. Это артефакты разговора, а не содержание.

### 3.3 Раздувание значимости

«Это стало поворотным моментом», «что подчёркивает важность подхода», «играет ключевую
роль в формировании», «является свидетельством приверженности».

**Что делать:** назвать факт. Значимость пусть оценивает читатель.

### 3.4 Избыточное хеджирование

«Возможно, можно было бы предположить, что…», «В определённой степени это потенциально
может…».

**Что делать:** говорить прямо: работает или не работает.

### 3.5 Пустые позитивные выводы

«Перспективы выглядят многообещающе», «Впереди захватывающие возможности»,
«Это открывает новые горизонты».

**Что делать:** закончить фактом, следующим шагом или просто остановиться.

## 4. Русские усилители машинности

### 4.1 Канцелярит

«Данный» вместо «этот», «является» вместо тире, «осуществляется» вместо глагола,
«в целях» вместо «чтобы», «в связи с» вместо «из-за», «в рамках» вместо «при».
Полная таблица — в `style-core.md`, раздел 3.

### 4.2 Номинализации

«Осуществление внедрения инновационных решений» — три действия, спрятанных в
существительных. «Обеспечение процесса оптимизации», «проведение мероприятий по повышению».

**Что делать:** найти глагол и построить предложение вокруг него.

### 4.3 Лишние притяжательные

«Вы можете использовать вашу учётную запись для входа в ваш личный кабинет» — калька
английского порядка.

**Что делать:** «Используйте учётную запись для входа в личный кабинет».

## 5. Кучи синонимов

| Машинный вариант | Человеческий |
|---|---|
| Быстро, точно и пунктуально | За полчаса |
| Мучается и страдает | Страдает |
| Постоянного, всеобъемлющего и непреходящего | Постоянного |
| Коротким, лаконичным, сухим и сдержанным | Сухим и сдержанным |
| Ясности и точности | Точности |

Если убрать одно слово и смысл не изменился — убирать. Если слова из разных категорий
(«имена, даты и статистика») — оставить.

Куча синонимов плюс правило трёх — очень сильный маркер. Такой абзац переписывают целиком.

## 6. Заумь

Сложные заимствования там, где есть простые русские слова: «имплементация» → «внедрение»,
«верификация» → «проверка», «трансформация» → «изменение». Полная таблица —
`pretentious-words.md`.

**Проверка:** сказал бы ты это коллеге за кофе? Если нет — упрощай.

## 7. Эвфемизмы

Машинный текст смягчает всё: проблемы становятся «вызовами», провалы — «зонами роста»,
увольнения — «оптимизацией». Если после прочтения непонятно, что проблема есть, —
эвфемизм убрать. Таблица — в `style-core.md`, раздел 4.

## Быстрая проверка

Найди в тексте три и больше признаков — нужна переработка, а не полировка:

- [ ] Кальки из раздела 1
- [ ] Две и больше троек подряд
- [ ] Пункты с жирным заголовком и двоеточием
- [ ] Абзацы одинаковой длины
- [ ] Нет первого лица и живой интонации
- [ ] Вывод ни о чём в конце
- [ ] Плотность канцелярита: данный, является, осуществляется
- [ ] Одно понятие названо четырьмя словами
- [ ] Тире в каждом втором предложении
- [ ] Хеджирование стопкой
- [ ] Кучи синонимов
- [ ] Три заумных слова в одном предложении
- [ ] Эвфемизмы вместо проблем
- [ ] Каждый абзац начинается с переходного слова
- [ ] Голословные утверждения без данных
