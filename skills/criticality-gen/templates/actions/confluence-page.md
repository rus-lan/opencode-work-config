# Action-пакет: страница оценки критичности в Confluence

> Сгенерировано `criticality.py start` из `templates/actions/confluence-page.md`; руками не править — меняйте `INFORMATION.yaml`.
> **Статус:** `{{ actions.confluence.status }}` — создать или обновить черновик (`draft`).

## 1. Параметры страницы

| Параметр | Значение |
|----------|----------|
| Заголовок | {{ actions.confluence.title }} |
| Родительская страница | {{ actions.confluence.parent_page_id | or_missing }} |
| Метка / статус | `criticality` / `draft` (до подтверждения SRE) |

## 2. Структура страницы

Разделы как в `CRITICALITY.md`, без frontmatter: паспорт · расчёт · входы · E2E-процессы · факты ИС · публикация · что не подтверждено · история оценок · источники.

## 3. Что приложить

| Артефакт | Путь | Состояние |
|----------|------|-----------|
| Паспорт (канонический YAML) | `{{ identity.code }}` → `criticality-passport.yaml` | сгенерирован |
| Человекочитаемый паспорт | `CRITICALITY.md` | сгенерирован |
| Расчёт и провенанс | `GENERATION.md` | сгенерирован |
| E2E-процессы | {{#if actions.e2e_list}}перечислены в `CRITICALITY.md` §4{{else}}{{ actions.e2e_text }}{{/if}} | — |

## 4. Как создать (вручную)

1. Открыть Confluence → создать дочернюю страницу под архитектурной страницей ИС
   (page_id из раздела 1).
2. Заголовок — из раздела 1.
3. Перенести разделы 1–10 из `CRITICALITY.md` (без frontmatter и без служебных
   комментариев).
4. Приложить `criticality-passport.yaml` и `GENERATION.md`.
5. Поставить метку `criticality`, оставить статус `draft`.
6. После подтверждения SRE — обновить статус и записать `approve_link`.

## 5. Чего в этом пакете нет

- **Пространство Confluence** — процессом не задано.
- **page_id новой страницы** — появляется только после создания.
- **Текст страницы** — не дублируется в пакете: источник истины — `CRITICALITY.md`
  этой же папки, чтобы не было двух расходящихся версий.
