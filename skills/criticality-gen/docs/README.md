# Документация: паспорта критичности ИС E001

## Когда читать

- Читать первым делом при работе с `docs/`: здесь карта остальных документов.
- Читать, когда неясно, какой документ отвечает на вопрос.
- Читать, когда добавляете или удаляете документ — обновите таблицу.

## Кратко

- Документация отвечает на четыре вопроса: **зачем** (процесс), **как считать** (методика), **что писать** (поля), **что делать руками** (runbook и скрипты).
- Номер в имени файла — порядок чтения, а не приоритет: `01`–`05` — процесс и правила, `06`–`07` — поиск и CLI, `08`–`12` — устройство инструмента.
- Машиночитаемые источники: `catalog.yaml` (реестр ИС, корень проекта) и [`criteria/criticality-criteria.yaml`](../criteria/criticality-criteria.yaml) (правила расчёта).
- Правила работы ИИ-агента в проекте — `AGENTS.md` в корне проекта.

## Термины

| Термин | Значение |
|--------|----------|
| ИС | Информационная система; в репозитории — папка `is/<код ИС>/` (например `is/erm.mm/`) |
| Контур | Технологический контур: `mm` (ММ) или `smkt` (СМКТ) |
| Актив | Бизнес-актив: ММ, СМКТ, СБЛ, СМ |
| SSoT | Single Source of Truth — карточка ИС в `ssot.ecom.tech` |
| `INFORMATION.yaml` | слой данных между SSoT и паспортом: авто-секции из SSoT + ручные входы критериев |
| dochub | Репозиторий архитектурной документации `architecture/app` |
| Паспорт | `criticality-passport.yaml` — канонический YAML для dochub |
| `CRITICALITY.md` | Человекочитаемая версия паспорта в той же папке |
| Переоценка | Повторный прогон методики; результат — `reassessment-<дата>.md` |

## Источники и актуальность

- Документы написаны по страницам Confluence; `page_id` указаны в каждом файле.
- Пользовательская документация процесса (методика, роли, регламент) ведётся в Confluence: [методика D6.1.1](https://space.samokat.ru/pages/viewpage.action?pageId=4552328348). `docs/` здесь — инженерная документация инструмента: как он устроен, как его ставить и поддерживать.
- При расхождении с источником приоритет у страницы-источника: правьте документ и указывайте, что изменилось.
- Дата актуальности — поле `updated` во frontmatter каждого документа.
