Методика расчёта метрик

История статусов — из jira_issue_history_hist (fieldname='statusName', поле newvalue). Время нахождения в статусе = до следующей смены статуса (или до resolved, если статус последний). PI (Initiative) и Epic без статуса Cancelled — в расчёт берутся только закрытые рабочей Done. CR считается по enddate/baselineenddate и не зависит от статусной истории.
