# Context7 MCP — проверка документации библиотек

Context7 — это MCP-сервер для получения актуальной, версионно-специфичной документации библиотек и примеров кода.

## Когда использовать

- **Перед использованием незнакомой функции/API** — запроси документацию через context7
- **При сомнении в сигнатуре** — вместо гадания, используй context7
- **При добавлении новой зависимости** — проверь текущий API через context7
- **При миграции версий** — проверь breaking changes через context7

## Как использовать

В промпте или при работе с кодом используй MCP-инструменты:
- `resolve-library-id` — найти ID библиотеки по имени
- `query-docs` — получить документацию по конкретному API

Или просто добавь в промпт: "use context7" — модель поймёт.

## Правила

1. **Всегда используй context7** когда:
   - Сигнатура функции вызывает сомнение
   - Нужна версия пакета, которой нет в node_modules
   - Документация библиотеки могла измениться после training data

2. **Можно НЕ использовать** когда:
   - Код пишется по готовой спеке/PIC
   - Используются примитивы языка/стандартной библиотеки
   - API уже проверен в текущей сессии

3. **Конфигурация**: MCP уже настроен в opencode.json как remote (`type: "remote"`, url: `https://mcp.context7.com/mcp`). Не требует установки, не создаёт дочерних процессов.

## Пример

