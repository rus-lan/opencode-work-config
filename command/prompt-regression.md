Проведи промпт-регрессию агентов конвейера. Цель: поймать деградацию ревьюеров после правок промптов или смены модели. Кейсы: `~/Documents/Assist/harness/prompt-regression/cases/`. Аргументы: $ARGUMENTS (пусто — все кейсы; можно перечислить имена через запятую).

## Сценарий

1. Прочитай `~/Documents/Assist/harness/prompt-regression/README.md` — формат case.yaml и правила зачёта.
2. Для каждого кейса собери песочницу во временной папке (`/var/folders/cw/s0nts15x0sd_d0c9l5bm26h00000gn/T/opencode/prompt-regression/<кейс>/`): `git init`, скопируй `common/` и файлы из `base:` case.yaml, закоммить; наложи файлы из `changed:`. Предмет ревью — незакоммиченный дифф рабочей копии.
3. Слепой прогон: @reviewer (и @reviewer-glm, если в case.yaml `agent: both`) — обычный запрос на ревью с путём к песочнице. Контекст теста не передавай: никаких слов про регрессию, дрель, golden-кейс. WORKFLOW_DIR — во временной папке кейса.
4. Оцени отчёт механически по `expect:` из case.yaml: вердикт совпадает точным токеном, каждая подстрока must_flag присутствует (регистр не важен), ни одна must_not не встречается, секции формата на месте. «Поймал» — только по этим правилам, без интерпретаций.
5. Сведи матрицу: кейс × агент → pass/fail + что именно не сошлось. Сравни с последним `prompt-regression-*.md` в `~/Documents/Assist/results/harness/`: просадка на кейсе, который раньше проходил, — главный сигнал регрессии.
6. Отчёт `~/Documents/Assist/results/harness/prompt-regression-<YYYY-MM-DD>.md`: матрица, версии промптов (`md5 -q ~/.config/opencode/prompts/reviewer.md ~/.config/opencode/prompts/reviewer-b.md ~/.config/opencode/prompts/verifier.md`), модели агентов. В watcher — только при изменении результата кейса (update факта 455 или новый факт).
7. Песочницы удали.

## Первый прогон — базовый

Первый запуск — калибровочный: кейс обязан проходить на текущих (эталонных) промптах. Если кейс не ловится — сначала чинят кейс или ожидания, а не промпты; кейс, который не проходит и после этого, удаляют. Только после зелёного baseline набор становится регрессионным.
